# BASE CAMP English モバイルアプリ 仕様書

- 対象：iOS / Android ネイティブアプリ（クロスプラットフォーム想定）
- ベース：プロトタイプ `index.html`（HTML/CSSモックアップ）を基に作成
- 本書はプロトタイプで確定したUI/UX・画面遷移・データ構造を実装用に文書化したもの
- カラー：ネイビー `#14365A` × 白 × コーラル `#E8825F`

## 3. トレーニングHub（`input_hub`）

トップに「今日の発話時間」ウィジェット（達成率リング＋分数）。以下3メニューを同列表示：

### 3.1 初級文法トレーニング（`unitmap` → `unitdrill`）

- ユニットマップ形式（UNIT表示、進行中/完了/未着手のステータス）
- ユニット詳細（`unitdrill`）：日別タブ、例文一覧、「答えを見る」トグル（※現状は表示切替のみのプレースホルダー。実装時は解答文言の出し分けが必要）

### 3.2 シチュエーション別課題（`situational`）

AIが生成する教材。2形式に大別：

**① ダイアログ形式**（複数人でのやり取りが本質的なシーン）

- 対象シーン：社内ミーティング／同僚との会話／社外でのやりとり
- `situational_dialogue`：AI生成の会話文（2バリアントを本日1回まで再生成可）
  - 各セリフに「再生」「スラッシュリーディング切替（セリフ単位）」「MYフレーズ登録」の3アイコンを吹き出し下部に配置
  - 全体を1本の音声として扱う共通プレイヤー（play/pause、±5秒/±10秒シーク、再生速度0.75〜1.5x）
  - 横スワイプでEN/JP切り替え（ページドット付き）
- `dialogue_roleplay`：全セリフを1画面に縦並び表示。相手のセリフ＝再生（何度でも可）、自分のセリフ＝録音→録り直す/確認する、を各行独立で操作。下部に一括「練習を終える」

**② プレゼン形式**（一人語りが本質的なシーン）

- 対象：プレゼンテーション
- `presentation_material`：4段落構成の長文原稿（2バリアント再生成可）。ダイアログと同じ音声プレイヤー／スラッシュリーディング／EN-JPスワイプ仕様
- `presentation_practice`：原稿全文を参照表示しつつ、通しで1回録音 → 提出してAI添削（合否＋コメント）

- 過去に生成した教材：最大5件をインラインプレビュー、超過分は `situational_history_full` で全件表示

### 3.3 フリー練習（`freetraining`）

- 音読／英語ピッチ／発音練習／Q&A練習／ロールプレイ／シャドーイングの6メニュー
- 現状はすべて `daily_task`（質問回答タイプ）に遷移する簡易実装。将来的にはカテゴリごとに専用コンテンツを持たせる想定

## 4. ミッションHub（`speaking_hub`）

トップに「今日の発話時間」ウィジェット（トレーニングHubと同一コンポーネント）。以下3メニュー：

### 4.1 Dailyミッション（`output` → `daily_task`）

- 2種類から選択：**写真描写ミッション**（写真を見て英語で説明）／**質問回答ミッション**（質問に英語で回答）
- フロー：録音（タイマー表示）→ 停止 → 確認する（音声プレイヤーで聞き直し）／録り直す → 提出してAI添削 → **合否＋添削コメント＋見本の解答例（英文/和訳）を表示**
- 履歴は `dailyMissionResults` に日ごとに1件蓄積（DAY番号・合否・種別）

### 4.2 Weeklyミッション（`weekly_material` → `weekly_practice`）

- 週替わりの長文教材（強み・弱み・キャリアを語る構成）。シチュエーション別課題プレゼン形式と同じ仕組み（段落・音声プレイヤー・スラッシュリーディング・EN/JPスワイプ）
- 練習画面で通し録音 → 提出してAI添削 → 合否＋コメント
- 履歴は `weeklyAssignmentResults` に週ごと1件蓄積（WEEK番号・合否）

### 4.3 Monthlyミッション（`mission`）

- 月1回のスピーチ課題「MYピッチ」。録音導線＋**スピーチ原稿メモ欄**（自由入力テキストエリア、下書き/コピペ用）
- 履歴は `monthlyMissionResults` に月ごと1件蓄積（MONTH番号・合否）

---

## 5. 動画（`lecture_list` → `lecture_player`）

- ホーム直下の独立タイル（トレーニングHubには含まない）
- 一覧：タイトル・講師名・再生時間・カテゴリタグ、視聴済みは完了バッジ表示
- プレーヤー：実際に再生可能な `<video>` 要素（controls付き）。「視聴済みにする」ボタンで完了マーク

---

## 6. MYフレーズ（`phrase` → `phrase_folder` / `quiz`）

### 6.1 カテゴリ管理

- 運営提供フォルダ（削除不可）とマイフォルダ（自作、削除可）を混在表示
- 「＋新規カテゴリ」でユーザーが自由にカテゴリ追加可能
- マイフォルダには削除ボタン（確認シート付き）

### 6.2 フレーズ登録（共通コンポーネント）

以下3箇所から起動する、アプリ内で唯一の登録経路：

1. ダイアログ画面：セリフごとの登録アイコン（テキストは自動入力・編集不可）
2. プレゼン/Weekly教材の「MYフレーズに登録する」ボタン（テキストは自由入力）
3. MYフレーズ画面 / カテゴリ画面の「＋フレーズを追加」ボタン

登録シート共通仕様：フレーズ本文（表示 or 入力）＋カテゴリ選択（既存チップ or その場で新規作成）→「登録する」

### 6.3 カテゴリ詳細・クイズ

- カテゴリタップ→フラッシュカード形式の学習画面（再生／和訳表示トグル／覚えたボタン）
- 「クイズにする」→出題数・出題順を選べるクイズ設定画面

---

## 7. 記録（`records`）

### 7.1 学習履歴セクション

- 個人／グループのスコープ切替、日別/週別/月別/全期間の期間タブ
- 棒グラフ（発話時間・その他学習時間の積み上げ）：**タップした棒の詳細を下の集計表に表示**（合否%表示は廃止、実績/目標の分数のみ）
- グラフ左右に「前後の期間ウィンドウへ移動」ナビ（日別=7日ずつ、週別=6週ずつ）
- 「＋新規登録」から任意の日に学習記録を直接追加可能

### 7.2 ランキングセクション（学習履歴の直下）

- 個人スコープ時：**全ユーザランキング**（約30名のモックデータ中でTOP10表示。圏外なら自分の順位を「…」区切りで別途表示）
- グループスコープ時：**グループ間ランキング**（自分の所属グループ＝aグループ vs 他5グループの合計学習時間で順位付け）
- 期間は学習履歴セクションの期間タブと連動（専用トグルは持たない）

### 7.3 カレンダーセクション

- 月表示。記録がある日は色付き＋ドット表示、タップで内容確認・編集
- 記録がない日をタップすると新規登録シートが開く（過去日への遡り記録が可能）

### 7.4 スピーキング履歴セクション

- Daily/Weekly/Monthlyミッションの結果と、フリー練習・シチュエーション別課題などの活動ログを**1本の履歴に統合**
- 種別フィルタ（全て/Daily/Weekly/Monthly/その他）と合否フィルタ（全て/合格/不合格）を独立して掛け合わせ可能
- 各行に種別ごとの合否バッジ（アイコンのみ、テキストなし）

### 7.5 グループ関連（`group_members` / `member_detail`）

- 「グループのメンバーを見る」からメンバー一覧・個人の週間学習時間・スピーキング履歴を閲覧可能（閲覧専用、コメント等の機能なし）

## 8. トーク（`talk_list`）

### 8.1 一覧構成（上から）

1. **aグループ**（グループチャット、複数人参加、送信者名を吹き出し上に表示）
2. スクールウィズ広告バナー（タップで `sw_lp` サンプルLPへ）
3. 運営からのお知らせ（公式・一方向配信のみ）
4. AI友達：Justin / Bob / Sara（英語）、セレン（日本語）※すべて通話可能
5. 田中コーチ／佐藤チューター（人間、通話不可）
6. カスタマーサポート（人間、通話不可、不具合・要望受付）

### 8.2 機能

- `talk_thread`：1:1チャット。AI相手は0.9秒後に自動返信
- `talk_profile`：アバター・種別（AI友達/コーチ・チューター/サポート/公式/グループチャット）・自己紹介文。通話可能な相手は電話ボタンを表示
- `talk_call`：通話画面（タイマー・ミュート・終了）。AI友達のみ利用可

## 9. マイページ（`mypage`）

### 9.1 プロフィール

- 全項目を表示（性別・年齢・音声性別・職業/職位・職業詳細・性格・趣味・経歴・成功体験・強み弱み・キャリア・仕事課題・今タームの目標）
- 編集は `mypage_edit` で個別フィールド編集

### 9.2 目標設定（`goal_history`）

- **1日の目標学習時間／発話時間**（分単位で数値入力、記録画面の目標値・達成率計算に直接反映）
- タームごとの目標履歴（過去の目標一覧＋「＋新しい目標」で追加）

### 9.3 過去の所属グループ（`past_groups` → `past_group_members`）

- 在籍期間ごとの所属グループ履歴と、当時のメンバー一覧（閲覧専用）

### 9.4 プラン（バナー → `plans`）

- マイページ最下部はコンパクトな「有料プランのご案内」バナーのみ。タップで専用LP画面へ
- 3プラン構成：
  1. 無料プラン（¥0/月）：AI添削基本機能・フリー練習・MYフレーズ・Dailyミッション
  2. 990円プラン（¥990/月、初回7日間無料）：全教材使い放題・Weekly/Monthlyミッション・詳細記録＆ランキング・動画講座見放題
  3. TEPPEN ENGLISHコーチング（お問い合わせ）：専属コーチ・週次フィードバック・学習設計。CTAで `coach_teppen`（自作サンプルLP）へ

## 11. 実装時の重要な注意点（プロトタイプではモック実装の箇所）

これらは見た目上は動作するが、**実際のバックエンド/AI連携が必要**な部分：

1. **AI添削（Daily/Weekly/Monthlyミッション共通）**：現状は3パターンの固定コメントからランダム表示。実際は録音の文字起こし（Speech-to-Text）＋LLMによる評価が必要
2. **録音機能**：タイマー表示のみ。実際のマイク録音・音声ファイル保存・アップロード処理が必要
3. **音声再生（シチュエーション別課題／Weekly教材の音声プレイヤー）**：経過時間を見た目上進めているだけ。実際はTTS（音声合成）で読み上げ音声を生成する必要あり
4. **シチュエーション別教材・Weekly教材の文章生成**：固定の2バリアントを切り替えているだけ。実際はプロフィール情報を元にLLMでその都度生成する想定
5. **動画講座**：全動画がダミーのサンプル動画（Big Buck Bunny）。実際の講座動画への差し替えが必要
6. **通話機能**：タイマーのみのモック。実際はWebRTC等のリアルタイム音声通信基盤が必要（実装負荷が高いため、後続フェーズでの実装を推奨）
7. **ランキング（全ユーザ／グループ間）**：固定の乱数生成データ。実際は全ユーザー・全グループの集計APIが必要
8. **ユニット詳細の「答えを見る」**：表示切替のみで実際の解答文言が出ない
